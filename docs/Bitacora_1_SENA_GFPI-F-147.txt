ACTIVIDAD 1
-----------
Descripción:
  Se realizó el análisis de requerimientos del sistema de gestión de turnos
  para empresa EMTRA EMT (Empresa de transporte), identificando las entidades
  principales que conformarían la base de datos.

Competencias aplicadas:
  Gestión bases de datos: Se aplicó el conocimiento de sistemas gestores de
  bases de datos relacionales (PostgreSQL) para diseñar, crear y estructurar
  las tablas del sistema, definiendo tipos de datos, llaves primarias, llaves
  foráneas, restricciones de integridad e índices para optimizar las consultas.

Fecha de inicio : 28/04/2026
Fecha de fin    : 30/04/2026

Evidencia de cumplimiento:
  Documento de análisis de requerimientos del sistema de gestión de turnos.

Observaciones / Dificultades:
  Se identificó la necesidad de implementar una arquitectura multi-tenant desde
  el inicio del proyecto, lo cual implicó rediseñar el modelo de datos para
  incluir el campo empresa_id en todas las tablas principales.

--------------------------------------------------------------------------------

  sus atributos y relaciones.

Fecha de inicio : 28/04/2026
Fecha de fin    : 30/04/2026

Evidencia de cumplimiento:
  Diagrama de entidad-relación con las 14 tablas diseñadas para la base
  de datos.

Observaciones / Dificultades:
